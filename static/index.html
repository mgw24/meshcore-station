COMPANION CHANNEL SLOTS
Channel management

 
Manage slots 0–7. Channel secrets are never displayed or returned to the browser. To rename an existing channel, leave the key empty; the collector reads and preserves the existing key on the radio. Saving a new key replaces the current key.

 
SLOTCHANNEL NAMESTATUS

 

 
Create or edit channel

 
 
 
 
 

 
Use the same name and 16-byte key as the mesh group you intend to join. Do not paste private keys into screenshots or chat.

 
Remove a channel
This deletes the channel name and shared key on the T114. It does not delete your message history.

 
 

 
Removing the Public channel (slot 0) requires explicit confirmation too. Back up any private channel keys before deletion.

Routing & Regions
These are outgoing Companion scope settings, not repeater allow/deny rules. No changes occur until you apply them.

 

  
Path hash
Longer paths help identify repeaters, but older repeaters may drop 2- and 3-byte hash packets.

   
Current hardware mode: not read

   
  

  
Default outgoing scope
Unscoped sends remain the safest option for broad compatibility until your network's region codes are confirmed. This does not change RF frequencies.

   
Scope status: not configured by Station

   
   
   
The firmware does not provide a reliable scope readback through the installed SDK. This setting is app-managed and reapplied after collector reconnects.

  

 

 

  
Saved region codes
Local code list. Names are community-defined, not automatically valid for Spokane. Adding a name does not change what repeaters allow.

   

   

  

  
Channel-specific scopes
Inherit the default, force unscoped, or use a region for channels 0–7. A temporary scope is restored after each channel transmit. A default must be configured first.

   

  

 

 
Apply changes
Changes are queued to the collector, which exclusively controls the USB radio. Path hash is read back after writing; scope acceptance is verified but cannot be read back independently.
